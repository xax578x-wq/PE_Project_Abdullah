# IT-Rules-v1_2026_10_15
 
Purpose: Five Desk rules for the Internal IT Help Desk. Each rule says who, what and when, and can be answered with yes or no.
Owner: Abdullah · Version: v1 · Date: 2026_10_15
 
| # | Area | Rule (who · what · when) | Yes/No check |
|---|------|--------------------------|--------------|
| 1 | Data | The agent replaces every name, username, email, phone number and device code with a code (User-1, Email-1, Device-X) and removes passwords and verification codes, before pasting any ticket, thread or answer into an AI tool. | Does the text still contain a real name, username, email, phone number, device code or password? (No = pass) |
| 2 | Verification | The reviewing technician compares every fact, number, date and time in a reply with the approved IT Help Desk Facts, and counts the questions and the answers, before the reply is sent. | Is every statement backed by a line in the Facts, and does the number of answers match the number of questions? |
| 3 | Fairness | The template owner runs the swap test (the same ticket with a different invented name, dialect or formality) and compares tone, length, facts and next step, before a template enters the library and after every change. | Are the two replies the same in tone, length, facts and next step? |
| 4 | Policy | The agent uses only AI tools approved by the organization, and the owner records the template version, the approver and the test date in the library index at every change. | Was an approved tool used, and is the record in the index? |
| 5 | Human decision | A technician approves every AI output before it is used. The AI never promises a date, approves a request or says an action was taken; a person decides laptop requests, access rights, complaints about staff and cases of a distressed employee. | Did a named technician approve the output, and is every decision made by a person? |
